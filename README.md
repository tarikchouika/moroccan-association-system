# منصة مامب (MAMP) — منصة إدارة الجمعيات المغربية

<div dir="rtl">

منصة رقمية احترافية لإدارة الجمعيات المغربية: الانخراطات، المحاسبة،
التبرعات، الفعاليات والوثائق الرسمية — متعددة الجمعيات، آمنة، ومتوافقة مع
الإطار القانوني المغربي.

## تطبيق أندرويد الرسمي

- **المشروع**: `app-android/` — غلاف ويب رسمي (WebView) للمنصة مع شاشة بداية،
  أيقونات تكيفية، صفحة انقطاع اتصال عربية وروابط عميقة. متطلباته Android 7.0+.
- **البناء الألي**: سير عمل GitHub Actions (`.github/workflows/build-apk.yml`)
  يبني APK موقّعاً عند كل تعديل على ملفات التطبيق وينشره في إصدارات GitHub
  باسم ثابت `mamp.apk` — ما يوفر **رابطاً دائماً** لآخر إصدار.
- **التوقيع الرقمي**: شهادة `CN=TARIK CHOUIKA` (RSA 2048 / SHA-256) بصلاحية
  **30 سنة** (2026–2056). المخزن وكلمة سره محفوظان كأسرار GitHub، ولا يظهران
  في المستودع أبداً. بصمة الشهادة والملف (SHA-256) تُنشران مع كل إصدار.
- **التوليد المحلي للمفاتيح** (عند الحاجة): `bash scripts/generate-signing-key.sh`
  ثم `python3 scripts/set-gh-secrets.py`.

## المزايا الرئيسية

### نظام متعدد الجمعيات
كل جمعية نطاق مستقل: بياناتها، أعضاؤها، محاسبتها، فعالياتها ووثائقها —
مع عزل صارم للصلاحيات بين الجمعيات.

### نظام صلاحيات هرمي (5 أدوار على مستوى المنصة)
- **SUPER_ADMIN** — مالك المنصة: الإشراف العام، توثيق الجمعيات، سجل التدقيق.
- **ASSOCIATION_ADMIN** — أعضاء مكتب الجمعية: التسيير الكامل لجمعيتهم.
- **CO_ADMIN** — المنخرطون والمتطوعون: صلاحيات محددة يمنحها المكتب.
- **PARTNER** — الجهات الحكومية والخاصة المختصة: اطلاع موثق.
- **CITIZEN** — المواطنون والأجانب: التصفح، التبرع، التسجيل في الفعاليات.

مع 8 أدوار داخل الجمعية (رئيس، نائب، كاتب عام، أمين مال، عضو مجلس،
كوأدمين، منخرط، متطوع).

### «المساعد الجمعوي» — شاتبوت بدون هلوسة
- يعمل بقاعدة معارف رسمية **مُتحقق منها يدوياً** (34 مدخلاً).
- **لائحة بيضاء للروابط**: لا يُعرض أي رابط خارج القائمة الرسمية الموثقة.
- فلترة إجبارية تمسح أي رابط غير موثق قبل العرض.
- في النسخة الثابتة يعمل باسترجاع حرفي من قاعدة المعارف داخل المتصفح —
  بدون توليد لغوي، فلا هلوسة ممكنة أصلاً.

### المحاسبة والامتثال
- عمليات مالية مصنفة (مدخول/مصروف) مع وصلات وموافقات.
- ميزانيات سنوية، واجبات انخراط، تبرعات نقدية وعينية.
- موافقة صريحة على معالجة المعطيات وفق **القانون 09.08 (CNDP)**.
- سجل تدقيق لكل العمليات الحساسة.

## البنية التقنية

| الطبقة | التقنية |
|---|---|
| الواجهة | Next.js 16 (App Router) + React 19 + Tailwind CSS 4 + shadcn/ui |
| الخادم | API Routes (Next.js) + JWT (jose) + scrypt |
| قاعدة البيانات | SQLite عبر Prisma ORM (تشغيل محلي) |
| الشاتبوت | z-ai-web-dev-sdk + قاعدة معارف موثقة + فلترة روابط |
| النشر العمومي | Cloudflare Pages (نسخة ثابتة) |

## التشغيل المحلي

```bash
# المتطلبات: Node.js 20+ أو Bun 1.1+

# 1) تثبيت الحزم
bun install

# 2) تهيئة قاعدة البيانات المحلية
bun run db:push
bun run db:seed          # بيانات تجريبية (4 جمعيات، 20 مستخدماً)

# 3) تشغيل النسخة الكاملة
bun run dev              # → http://localhost:3000
```

### بناء ونشر النسخة العمومية الثابتة
```bash
bash scripts/build-static.sh                    # يبني في out/
npx wrangler pages deploy out --project-name=mamp
```

## المرجعية القانونية
المنصة مبنية على الإطار القانوني المغربي للعمل الجمعوي:
- الظهير الشريف رقم 1.58.376 (15 نونبر 1958) بتنظيم حق تأسيس الجمعيات.
- القانون 75.00 المغير والمتمم للظهير (2002).
- القانون 07.09 المعدل للفصل 5.
- دستور 2011 (الفصلان 12 و29 — الديمقراطية التشاركية).
- القانون 09.08 لحماية المعطيات ذات الطابع الشخصي (CNDP).

## الأمان
- كلمات السر مشفرة عبر scrypt مع ملح عشوائي.
- جلسات JWT موقعة داخل كوكي httpOnly.
- سجل تدقيق شامل للعمليات الحساسة.
- الأسرار (مفاتيح الرموز) خارج المستودع في `.secrets/` المحلي.
